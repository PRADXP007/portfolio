# Pradeep H — Engineering Portfolio

> **Production-grade personal engineering portfolio website** for **Pradeep H**, built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Lenis smooth scroll, Framer Motion, and WebGL hardware circuit shaders.

Matching the **Stitch Design System** ("Atelier Archive" / Warm Parchment `#F3ECE0` × Deep Maroon `#5C1A28`).

---

## ✨ Features & Architecture

- **Aesthetic**: Warm Parchment (`#F3ECE0`) & Deep Maroon (`#5C1A28`) palette with subtle organic SVG grain texture.
- **Typography**: Google Fonts `EB Garamond` (display serif) paired with `Manrope` (clean geometric sans).
- **Liquid Glass (`<GlassPanel>`)**: `backdrop-blur-xl` panels with hairline maroon borders and soft warm-toned shadows.
- **Adaptive Sticky Navigation**: Starts full-width transparent and smoothly compresses into a floating liquid glass pill after 80px scroll.
- **WebGL Hardware Circuit Shader**: Custom GPU shader in the hero section featuring interactive mouse reactivity and accessibility fallbacks.
- **Buttery Smooth Scroll**: Whole-page inertia scrolling powered by **Lenis** with `prefers-reduced-motion` compliance.
- **Spatial 3D Tilt Cards**: Cursor-linked 3D parallax tilt (`rotateX`/`rotateY`) on software and hardware cards with detailed spec modals.
- **Blueprint Schematic System**: Technical grid styling for low-level embedded & RF antenna engineering projects.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm, pnpm, or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/PRADXP007/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or specified port) to view the application.

### Production Build
```bash
npm run build
npm run start
```
